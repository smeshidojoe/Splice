# Splice

[English](README.md) · **Русский**

Нарезка видео на куски — или нарезка со склейкой — прямо из меню проводника.
Без перекодирования: быстро и без потерь.

</div>

## Скачать

1. Откройте страницу [Releases](https://github.com/SmeshidoJoe/Splice/releases/latest).
2. Скачайте `Splice-Setup-….exe` и запустите. Права администратора не нужны.
3. При первом запуске Splice предложит скачать FFmpeg (около 80 МБ) — соглашайтесь.

Работает на Windows 10 и 11.

## Как пользоваться

**Нарезка.** Правый клик по видео → **Нарезать в Splice** (в Windows 11 —
«Показать дополнительные параметры»). Поставьте начало (`I`) и конец (`O`),
`Enter` добавит фрагмент. Фрагментов сколько угодно; **Сохранить** — и каждый
ляжет рядом с исходником как `имя_part1`, `имя_part2`… Края фрагмента на
таймлайне можно тянуть мышью.

**Merge Chopped.** Включите — и все фрагменты нарежутся и склеятся в один файл
`имя_chopped`, тоже без перекодирования.

**Склейка.** Выделите несколько видео → **Склеить в Splice**. Порядок меняется
перетаскиванием. У файлов должны совпадать кодек, разрешение и формат звука —
иначе Splice предупредит.

Без перекодирования рез может начаться только с ключевого кадра, поэтому
фрагмент начинается с ближайшего ключевого кадра перед точкой начала.

| Клавиша | Действие |
| --- | --- |
| `Пробел` | воспроизведение / пауза |
| `I` / `O` | начало / конец |
| `Enter` | добавить фрагмент |
| `Del` | убрать выбранный |
| `←` `→` | на кадр (`Shift` — 1 с, `Ctrl` — 10 с) |
| `[` `]` | к началу / концу фрагмента |
| `Ctrl + S` | сохранить |

## Сборка

```
pip install -r requirements.txt pyinstaller
python tools_gen_assets.py
pyinstaller --clean --noconfirm Splice.spec
iscc splice_setup.iss
```

Из исходников: `python main.py файл.mp4`; `python main.py --register` добавит
пункты меню для рабочей копии (`--unregister` уберёт).
